# Rewrite card

Template for **bar for bar** mode. One row per sentence. The explanation column is capped at one clause on purpose, because a card nobody can read forty times teaches nothing.

---

## Format

```
s4   18 -> 9
     WAS:  The primary consideration when evaluating a vendor is whether
           they have demonstrated capability in your specific vertical.
     NOW:  Pick the vendor who has done it in your industry.
     WHY:  cut the preamble, hard landing
```

Syllable counts first, before the text, so the shape is visible while scrolling.

---

## The why column

One clause. Pick from the list or write something equally short.

**Breath**
- split at the conjunction
- punctuated, same words
- cut the preamble
- subject moved up front

**Variance**
- cut to a fragment, run was flat
- lengthened, three shorts in a row
- merged with the next one

**Landing**
- hard landing
- killed the passive
- ended on a verb
- removed the trailing qualifier

**Room**
- flattened, it was competing with s3
- moved, belongs in section 4
- cut, redundant with s7

**Sound**
- stop consonant on the last beat
- shorter words, same meaning
- fixed a stumble

**No change**
- left alone, carries a number
- left alone, voice
- left alone, format wants flat

---

## Rules for this mode

**Every sentence gets a row,** including the ones that did not change. A card showing only the rewrites hides how much was left alone and makes the pass look more aggressive than it was.

**Counts are measured, not estimated.** Run the script on the before and after rather than guessing.

**No sentence gets two reasons.** If a rewrite did three things, name the one that drove it. The others came along.

**If the rewrite is longer, say so and justify it.** Most fixes shorten. The ones that lengthen are usually right and always look wrong, so they need the note.

---

## Summary block

End the card with this, filled in.

```
_ sentences, _ changed, _ left alone
Overall _/5 -> _/5
Lowest axis _ -> _

Lost in translation: (any fact, number, name, or qualification that did
not survive, or "nothing")
```

The last line is not optional. If something was lost, the rewrite is wrong and the original stands.
